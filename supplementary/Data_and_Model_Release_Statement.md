# Method Implementation Statement

This repository provides the PG-PDN method implementation associated with the manuscript "Physics-guided pavement degradation prediction from grid-level semantic distress maps".

## Provided Materials

- PG-PDN source code and configuration files.
- Feature names, tensor shapes, units and constraints for the PG-PDN input contract.
- Equation-to-code mapping for the Section 3 physical branch, residual branch and loss terms.
- PaveVision UI boundary documentation.
- Supplementary method notes and method inspection documentation.

## Method Inspection Path

The repository supports the following source-level inspection path:

1. Inspect the PG-PDN model equations, feature order and loss terms.
2. Review the 12-field input contract.
3. Review the default physical-branch parameters and loss weights.
4. Inspect the PaveVision UI boundary.

## Notes

The repository is focused on method implementation, configuration and interface definition.
